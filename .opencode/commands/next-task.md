---
description: 执行任务清单里下一个未完成的任务，并跑通验收
---

开始一个任务。严格按 `AGENTS.md` §5 的流程执行：

1. 读取 `docs/一期-任务清单.md`，选出**编号最小的未勾选任务**。
2. 读取 `docs/一期-技术方案.md` 中与该任务对应的章节（任务行的"设计"列有指引）。
3. 先用 3 行说明：要改哪些文件、核心思路、可能的坑。然后开始写代码。
4. 只碰该任务相关文件，不做额外重构、不顺手改格式。
5. 运行 `pnpm verify`，全绿才算完成；失败就修，**不要靠改测试/关 lint 规则绕过**。
6. 勾选 `docs/一期-任务清单.md` 里的 checkbox，行末补 `— ✅ 一句话总结`。
7. 汇报：改了什么 / verify 输出摘要 / 下一个任务是什么。

补充规则：

- 带 🔒 的任务（T06 / T12 / T16 / T20 / T28）必须**先讲思路、等我确认**再动代码。
- 需要新增依赖时停下来问，不要直接 `pnpm add`。
- 如果实现与 `docs/一期-技术方案.md` 不一致，先说明原因，我同意后再改文档。

如果 `$ARGUMENTS` 里给了任务号（例如 `T06`），直接做那个任务。
